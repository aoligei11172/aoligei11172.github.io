TypeScript入门

2026/5/10 typescript

TypeScript是 JavaScript 的超集，意味着任何有效的 JavaScript 代码也是有效的 TypeScript 代码。

TS具有静态类型检查，编译时检查，不用等到运行时报错

TS需要转换成js才能运行，在终端中操作

手动转化：

tsc index.ts

自动转化：

tsc --watch

变量声明

变量声明以let和const为主

let 变量名: 类型 = 初始值;
const 常量名: 类型 = 值;

类型名推荐小写

新增类型

any

任意类型，意味着放弃了对该变量的类型检查。

any类型的变量可以赋值给任意类型的变量

例如:

let a: any
a = false
let b: string
b = a
console.log(b) //打印false

unknown

未知类型，相当于安全的any

不能直接赋值或使用某种变量类型的方法，需要判断类型:

let a: unknown
a = 'hello'
let b: string
if(typeof a === 'string') x=a //方法1
x = a as string //方法2
x = <string>a //方法3

never

不能被赋任何值，包括undefined，null等

void

用于函数，表示函数的返回值为空

可以无返回值或者返回undefined

tuple

tuple(元组)是一种特殊数组类型，可以存储固定数量的元素且类型已知，可以不同。?表示可选元素。不是关键字

声明：

let arr1: [string,number]
let arr2: [number,...string[]]

enum

enum枚举可以定义一组命名常量，支持双向映射(仅限数字枚举)

声明：

enum Direction {
  Up,      // 默认值 0
  Down,    // 1
  Left,    // 2
  Right    // 3
}

let move: Direction = Direction.Up;
console.log(Direction);
//  { "0": "Up", "1": "Down", "2": "Left", "3": "Right", "Up": 0, "Down": 1, "Left": 2, "Right": 3 }双向映射
console.log(move);        // 0
console.log(Direction[0]); // "Up"（反向映射）

常量枚举：enum前加const，让ts编译时将枚举成员引用替换成真实值而不是额外生成对象，减少代码量

type

用于定义类型别名，适用于任何类型

type MyString = string;
type Point = { x: number; y: number };
type Callback = (data: string) => void;
type Coord = [number, number, number?];  // 可选元组

联合类型

type a = number | string

合并类型

type A = {a: number}
type B = {b: string}
type C = A & B

泛型

允许在定义函数，类，接口时，使用类型参数表示未指定的类型，这些参数在具体使用时才指定类型。让代码适用于多种类型，并保持安全性

function logData&lt;T&gt;(data: T){
	console.log(data)
}
logData&lt;number&gt;(100)
logData&lt;string&gt;('hello')

用<>声明时内部通常用T，也可自定。
