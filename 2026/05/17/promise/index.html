Promise

2026/5/17 JavaScript

回调地狱

在异步编程中，过多嵌套的回调函数导致代码难以阅读、维护和排错的现象，即回调函数中嵌套回调

Promise

Promise是 JavaScript 中为了解决回调地狱而诞生的异步编程方案

是一种构造函数，通过new实例化对象

const fn = new Promise((resolve, reject) => {
  // 异步操作
});

promise实例

实例中有两个属性

  • state：状态
  • result：结果

三种状态（state）

pending(准备，待解决)

fulfilled(已完成，成功)

rejected(已拒绝，失败)

通过调用resolve()和reject()来改变状态

  • resolve() 改变为fulfilled
  • reject()改变为rejected

结果（result）

resolve()和reject()可以用来改变Promise的结果

const fn = new Promise((resolve, reject) => {
    resolve('hello');
})
console.dir(fn); 
//输出：
//    Promise
//      [[Prototype]]: Promise
//      [[PromiseState]]: "fulfilled"
//      [[PromiseResult]]: "hello"

then方法

是处理异步操作结果的核心方式

promise.then(onFulfilled, onRejected);
  • onFulfilled当Promise状态为fulfilled时执行，可以传入Promise 的 resolved 值
  • onRejected当Promise状态为rejected时执行，可传入即 Promise 的 rejected 原因

二者只能传入一个参数。

返回Promise对象，状态为pending。可以继续.then()

例如：

const fn = new Promise((resolve, reject) => {
    resolve(5);
})
fn.then((num) => {return num * 2})
  .then((num) => console.log(num)); //输出10

catch方法

.catch()用于捕获Promise发生的错误，是.then(onRejected)的语法糖

语法：

promise.catch(onRejected);

例：

const fn = new Promise((resolve,reject) => {
    throw new Error('!出错了!');
})
fn.catch((onRejected) => console.log(onRejected)); //返回Error: !出错了!
