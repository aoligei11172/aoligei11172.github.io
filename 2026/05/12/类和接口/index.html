typescript 类和接口

2026/5/12 typescript

类

类(class)是面向对象编程的核心，是一种基于原型链的语法糖。

定义：

class Person{
	name: string;
    age: number;
    constructor(name:string,age:number){
        this.name=name;
        this.age=age;
}
}

也可简写成：

class Person{
	constructor(public name:string,public age:number){}
}

类修饰符

public

默认，任何地方可以访问

protected

当前类及子类内部可以访问

private

仅当前类内部可以访问

readonly

只读，不可修改

抽象类

抽象类用abstract声明，不能被实例化，只能作为其他类的父类，其中部分方法已实现，部分方法只声明不实现(抽象方法)，用abstract声明，由子类完成

定义：

abstract class Package {
	constructor(public weight: number) {}
    printPackage(){
        console.log(`weight: $(this.weight`)
    } //已实现方法
    abstract calculate(): number
    //未实现方法
}

接口

接口（Interface）是一种定义结构的方式。只能定义格式，不包含任何实现

定义

对象和类

对象和类都通过interface关键字定义 ，但声明具体内容有所不同

interface IPerson {
	name: string;
    age: number;
    speak(n: number): void;
}

class Person implements IPerson{
	constructor(public name: string,public age:number) {}
    speak(n: number):void {
		console.log(`${n}`)
    }
}  //接口定义类
const User: IPerson = {
	name: "张三",
    age: 18,
    speak(n) {}
} //接口定义对象

函数

interface Count{
    (a:number,b:number): number;
} //定义函数参数和返回值类型

继承

接口之间可以用extends关键字来继承

interface PersonI {
    name: string;
}
interface Person extends PersonI {
	age: number;
    //继承PersonI，自带name属性
}
