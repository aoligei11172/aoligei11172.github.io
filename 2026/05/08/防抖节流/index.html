防抖 节流

2026/5/8 -JavaScript

防抖

单位时间内频繁触发事件，只在最后一次触发后等待一段指定时间，才执行一次函数。

原理：

  1. 每次事件触发时，清除之前的定时器。
  2. 重新设置一个新的定时器。
  3. 只有当两次触发之间的间隔大于设定的等待时间，定时器才会执行真正的函数。

1.手动实现

function debounce(fn, delay) {
  let timer;
  return function() {    
  	if(timer) clearTimeout(timer);
    timer = setTimeout(() => {
      fn();
    }, delay);
  };
}

2.通过lodash库中_.debounce

_.debounce(func,wait)

节流

它确保一个函数在一定时间间隔内最多执行一次，即使在此期间该函数被无数次调用。可以节流就是限制执行频率的工具提高性能。

1.通过lodash库中_.throttle

_.throttle(func, [wait=0]

2.手动实现

function throttle(fn, delay = 200) {
  let lastTime = 0;
  return function() {
    const now = Date.now()
    if (now - lastTime >= delay) {
      lastTime = now;
      fn();
    }
  }
}

关系对比

防抖在于连续触发时执行最后一次，节流在于连续触发时只执行一次

例如：

// 防抖：持续触发时不执行，停止后执行最后一次
const debounced = debounce(() => console.log('debounce'), 200);
//连续调用只调用最后一次

// 节流：每200ms至少执行一次
const throttled = throttle(() => console.log('throttle'), 200);
//连续调用，每200ms调用一次
