this处理

2026/5/8 JavaScript

普通函数

普通函数的this由调用方式决定，谁调用那么this就指向谁

没有明确调用者时，非严格模式this的值为window，严格模式下独立调用的函数的this为undefined

箭头函数

箭头函数没有自己的this，但会默认绑定外层this。因此箭头函数的this的值和外层的this一样。在外层作用域一层层查找直到有this的定义,且无法通过call/bind/apply改变

构造函数

通过new调用时，this指向新创建的实例

事件处理

DOM 事件回调中，普通函数的 this 指向绑定事件的元素；箭头函数的 this 则保持外层定义时的值。

改变this

call()

立即执行函数，可手动指定this，并按顺序把后面的参数传入函数

fun.call(thisArg,arg1,arg2...)

apply()

作用和call相同，后面的参数是数组而不是单个参数

bind()

不执行和改变原函数，返回一个新函数,新函数的this被绑定到第一个参数，可以预设部分参数

func.bind(thisArg, arg1, arg2, ...)

例：

obj = {}
function fn () {
	    console.log(this);
}
const f = fn.bind(obj);
f() //返回 {}
fn() //返回window对象
